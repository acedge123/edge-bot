# UI/UX Layout Advisor

## Use

Apply this when the user wants feedback on a landing page, interface, wireframe, homepage, funnel, or screen layout, especially when the goal is clearer hierarchy, better spacing, stronger readability, or cleaner UX.

## Workflow

1. Identify the page goal, user task, and primary call to action.
2. Review information hierarchy, spacing, alignment, and scanability.
3. Check whether important elements are visually prioritized.
4. Suggest layout improvements that reduce clutter and improve usability.
5. Include accessibility considerations when they materially affect clarity or interaction.

## Review focus

- Visual hierarchy
- Spacing and alignment
- CTA prominence
- Readability and content grouping
- Form and interaction clarity
- Mobile and responsive concerns
- Accessibility basics

## Output shape

- Layout recommendations, or
- Structured review notes, or
- Suggested element order and positioning, with optional visual hints

## Rules

- Prioritize clarity over decoration.
- Do not overcrowd the layout.
- Keep recommendations practical and specific.
- Favor simple hierarchy that supports the main conversion or task.
- Note when a problem is about content, not just layout.

## Good fits

- Landing page reviews
- UI critique
- Wireframe feedback
- Homepage or funnel layout advice
- Form and dashboard usability review
- Conversion-oriented page structure

## Constraints

- Do not recommend changes that add complexity without clear UX value.
- Do not optimize for aesthetics at the expense of usability.
- Keep the layout readable, scannable, and intentional.
