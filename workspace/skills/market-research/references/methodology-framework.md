# Methodology Framework

Use this file when choosing or critiquing a design.

## 1. Start from decision type

| Decision type | Best-fit methods | Notes |
| --- | --- | --- |
| Discover unmet needs / language / tensions | IDIs, mini groups, ethnography, diary, community mining | Best for exploration, not prevalence claims |
| Prioritize messages / concepts / offers | Quant survey, message test, structured qual, hybrid | Need clear stimuli and tight hypotheses |
| Understand cohort differences | Quant with adequate sample, segmented qual as precursor | Do not claim segmentation from tiny n |
| Measure activation or event impact | Pre/post survey, intercepts, behavior + sentiment combo, longitudinal pulse | Pair attitudinal and behavioral signals |
| Track change over time | Repeated pulse, panel, longitudinal cohort | Consistency matters more than instrument sprawl |
| Generate hypotheses fast | Lean qual, community scraping/synthesis, directional pulse | Useful when budget/time is constrained |

## 2. Choose the confidence level

### Exploratory
- Best for: discovery, hypothesis generation, message mining
- Typical methods: IDIs, small groups, diaries, community listening
- Limitation: cannot support strong prevalence or causal claims

### Directional
- Best for: lean decision support under budget/time pressure
- Typical methods: quick-turn survey, small hybrid design, intercept studies
- Limitation: should not be sold as nationally representative certainty

### Decision-grade
- Best for: higher-stakes prioritization, segmentation, sizing, validation
- Typical methods: better-powered quant, rigorous sampling, phased mixed methods
- Limitation: slower and more expensive

## 3. Common design patterns

### Qual only
Use when the main need is understanding motives, language, reactions, or emotional context.

Good for:
- early-stage positioning
- concept exploration
- journey friction
- community/creator insight work

Weak for:
- sizing demand
- ranking segments with confidence
- making numeric prevalence claims

### Quant only
Use when the main need is comparison, incidence, prioritization, or measurement at scale.

Good for:
- concept tests
- message prioritization
- directional sizing
- attitudinal benchmarking

Weak for:
- understanding why without prior framing
- messy emerging-category exploration

### Hybrid phased design
Use when the problem is ambiguous and the final decision still needs some measurement.

Typical pattern:
1. exploratory qual
2. instrument design / hypothesis refinement
3. quant validation
4. synthesis and recommendations

This is usually the safest answer when the brief mixes discovery and validation.

## 4. Sample-size heuristics

Use these as rough heuristics, not promises.

- **6-12 IDIs per meaningful subgroup** is often enough for directional thematic coverage.
- **2-4 mini groups** can work for reaction and co-interpretation, but group dynamics distort individual truth.
- **n~100** is directional only for narrow, low-stakes reads. Avoid segmentation claims.
- **n~200-300** can support stronger directional reads for a defined audience.
- **n~400+** is a more credible floor when the user wants subgroup comparisons or segmentation-lite decisions.
- **True segmentation / advanced subgrouping** often needs materially more sample, depending on number of segments and variables.

Always condition sample commentary on:
- audience rarity
- geography
- incidence assumptions
- number of subgroups
- precision needed for the decision

## 5. Red flags to call out

- one study trying to answer too many unrelated questions
- too many audience cuts for the available n
- national language with non-national sampling
- qualitative output presented as statistical evidence
- survey instrument likely to exceed realistic attention span
- custom recruit with niche criteria and no time budget
- timeline shorter than recruit + field + synthesis reality

## 6. Faster/cheaper substitutes

When the ideal design is too expensive or slow, consider:

- a two-phase plan with an exploratory first wave
- community pulse instead of broad panel quant
- intercepts around an activation instead of nationwide survey
- fewer segments with sharper decision framing
- concept triage before full testing
- reusing existing community/admin data before fresh fieldwork

## 7. What to state explicitly in recommendations

Always mention:
- what the method can answer well
- what it cannot answer
- what confidence level the user should attach to the output
- what assumptions could break the plan
