# Excalidraw Diagram Generator

## Overview

Turn messy ideas into diagram-ready structure. Produce concise, visual-first instructions that a person can paste into Excalidraw or another diagramming tool, especially for architecture, workflow, and permission-flow reviews.

## Core workflow

1. Identify the goal of the diagram.
2. Extract the main entities, stages, and relationships.
3. Choose a layout that matches the shape of the problem.
4. Output nodes, connections, labels, and grouping.
5. Keep the diagram uncluttered and easy to scan.

## Output format

Use this order:
- Title
- Purpose
- Nodes
- Connections
- Layout suggestion
- Optional notes for clarity

## Rules

- Prefer fewer, clearer nodes over exhaustive detail.
- Use short labels.
- Show direction of flow when relevant.
- Group related items.
- Call out swimlanes, layers, or phases when helpful.
- If the input is ambiguous, pick the simplest coherent structure.

## Good fits

- Product or system architecture maps
- Workflow and process diagrams
- Org or permission flows
- Decision trees
- Customer journey or funnel visuals

## Deliverables

When helpful, describe:
- node types
- arrows or connectors
- hierarchy or nesting
- recommended left-to-right, top-down, or radial layout
